📘 INSTRUCTIONS

KAISE KHELNA HAI

  • Pehle REGISTER ON WHATSAPP se entry fee bhejo. Admin jo username dega, wahi START QUIZ mein daalo (optional referral code bhi).
  • Har sawal ke 4 option hain, 1 sahi. Option dabate hi agla sawal aa jata hai.
  • Quiz khatam hone par apne EP points, rank aur result card milta hai.

POINTS (EP)

  • Har sahi jawab = 20 EP.
  • Har sawal par 59 second milte hain. Bache hue har second ka +1 EP.
  • 🔥 Streak bonus: lagatar 3 ya zyada sahi jawab par har sahi jawab ke saath +5 EP extra.
  • Galat ya time-out = 0 EP, aur streak toot jati hai.
  • Highest possible: 1670 EP (20 × 79 = 1580, plus streak bonus 90). Practically thoda kam, kyunki tap karne mein 1-2 second lagte hain.

INAAM (TOP 5)

  • Match khatam hone par leaderboard ke Top 5 ko inaam milta hai. Rashi upar dikhti hai.
  • Winner apna username WhatsApp support par bhejein.
  • Points barabar hon to jiske sahi jawab zyada wo upar, phir jiska total time kam ho.

EARN MONEY (NAVI TASK)

  • ⚙ Settings mein "Earn Money" kholo aur Navi task poora karo: app download karo aur first payment karo.
  • Task ke baad "Task completed?" dabake YES karo, aapka message WhatsApp par chala jayega.
  • Sirf naye users valid hain, aur app 5 din use karna hai.

STUDY PDFs AUR REFERRAL

  • ⚙ Settings mein "Study PDFs" se Police Bharti (Marathi) ya UPSC (Hindi) PDF kharid sakte ho. BUY ON WHATSAPP dabake payment karo, screenshot bhejo, PDF WhatsApp par milegi.
  • "Refer & Earn" mein aapka apna referral code hai. Dost aapke link se aake pehla quiz poora kare to aapke wallet mein ₹1 aata hai. ₹10 hone par redeem code claim karo.

RULES

  • Ek username aur ek device se sirf ek hi baar khel sakte hain (admin ke liye limit nahi).
  • Quiz beech mein chhodne ya refresh karne par dubara chance nahi milega.
  • Match ka timer upar dikhta hai. Match shuru hone se pehle ya khatam hone ke baad quiz nahi khel sakte.
  • Quiz ke baad aapke har jawab ka review aur explanation dikhta hai.
  • Admin ka faisla final hoga.
